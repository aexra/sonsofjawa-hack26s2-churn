# Проверка модели риска

Это первая порция ML-ядра, а не готовое Spring Boot приложение. Миграции лежат в будущем стандартном пути Flyway. `V1` содержит исходную схему, `V2` — только служебную схему модели без пользователей и аутентификации; номера миграций необходимо согласовать при интеграции backend. В существующей среде с применённой историей Flyway версионные миграции не заменять.

Источник архитектуры и исходных SQL-эскизов: соседний репозиторий `docs-agents`, файлы `docs/risk-model.md`, `docs/sql/V2__core.sql`, `docs/sql/R__risk_model.sql`. `fixtures/organizer.json` дословно сохраняет синтетический набор `source/tmplt/data.json`: 10 аккаунтов, 30 услуг, 100 транзакций. `docs-agents` и `infra-prod` не изменяются.

## Запуск

Из корня `service`:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s apps/api/src/test/ml -p 'test_*.py' -v
```

Нужны Python 3.10+, Docker CLI и работающий Docker Engine. PostgreSQL 18 Alpine закреплён digest в тесте. Первый запуск может скачать образ. Тесты создают отдельный контейнер со случайным именем, без сети и опубликованных портов, с временной БД в tmpfs. Внешние БД, существующие контейнеры и пользовательские тома не используются. Контейнер удаляется после выполнения, включая ошибки тестов.

## Первая порция

Воспроизводит исходную формулу из `docs-agents` на фиксированном времени `2026-10-19T15:00:00Z`: 3 high, 1 medium, 2 low, 4 без оценки; сумма `expected_loss` 719520 евроцентов. Проверяет изменение весов, повторное применение модели с сохранением настроек, отсутствие оценки, удаление аккаунта и границы результатов.

Исходная модель эвристическая: score не является откалиброванной вероятностью. Исходная денежная оценка и признаки будут исправлены отдельной порцией с обновлением эталонов и объяснением допущений. До этого эти результаты служат контрольной точкой переноса, а не верификацией экономической модели.
