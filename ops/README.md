# ops

- `compose/` — Compose-файлы: основной стек, оверрайд для разработки, профиль наблюдаемости.
- `config/` — конфигурация Prometheus.
- `observability/` — провижининг и дашборды Grafana.
- `scripts/` — загрузка демо-данных, генератор демо-набора, ожидание готовности сервисов.
- `seeds/` — тестовые данные организаторов (`tmplt/`) и расширенный демо-набор (`demo/`).
- `Makefile` — цели стека; вызываются из корневого `Makefile`.
